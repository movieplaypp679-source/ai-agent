On-device AI · phone ke andar

Model chuno aur Download dabao. Progress real % mein dikhega. Pause/Resume kaam karta hai, net toot jaye to wahin se aage badhega. Download ke dauran app khula rakho.
Apni khud ki .task file phone se seedha import karo (jaise browser se download ki hui, ya Gemma/Phi ki).

Server connection

Wo service ki website par "API"/"Developers" section mein milta hai.
